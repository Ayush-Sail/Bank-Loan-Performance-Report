📊 Financial Loan Intelligence Report
📝 Project Overview
This project provides a data-driven analysis of a banking institution's loan portfolio. The primary goal is to monitor and assess loan applications, funding trends, and repayment health to support strategic decision-making and risk management.
🔑 Key KPIs & Metrics Analyzed
Total Loan Applications: Tracking the volume of loan requests over time.
Total Funded Amount: Monitoring the total capital disbursed to borrowers.
Total Amount Received: Evaluating the efficiency of repayments and cash flow.
Average Interest Rate: Analyzing the cost of borrowing across different loan grades.
Average DTI (Debt-to-Income): Assessing the financial health and risk profile of borrowers.
🛠️ Features
Executive Summary: A high-level view of all critical banking metrics.
Regional Analysis: Geographical breakdown of loan distribution (e.g., USA State Map).
Loan Performance Categorization: Distinguishing between 'Good' and 'Bad' loans based on repayment status.
Dynamic Filtering: Ability to slice data by loan grade, sub-grade, and issue date.
💻 Tech Stack
Tool: Power BI Desktop
Data Modeling: Star Schema / Snowflake Schema
Calculations: Advanced DAX (Data Analysis Expressions) for complex measures.
Visualizations: Donut charts, Tree maps, Geographic maps, and Gauges.
